# Pergunta 1

Os comandos **GRANT** e **REVOKE**, utilizados para gerenciar privilégios de acesso aos dados, pertencem a qual subconjunto da linguagem SQL?

```
A. TCL ()
B. DDL ()
C. DCL ()
D. DML ()
```

  * **A. TCL (Transaction Control Language)** → `COMMIT`, `ROLLBACK`, `SAVEPOINT`.
  * **B. DDL (Data Definition Language)** → `CREATE`, `ALTER`, `DROP`, `TRUNCATE`.
  * ✅ **C. DCL (Data Control Language)** → `GRANT`, `REVOKE`.
  * **D. DML (Data Manipulation Language)** → `SELECT`, `INSERT`, `UPDATE`, `DELETE`.
